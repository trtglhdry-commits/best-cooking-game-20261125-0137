Sizzle & Serve — a little warung cooking game. Cook to order across a 150-second shift: chop ingredients on the board, fry them in the wok, grill satay, mix iced tea, plate each dish and serve it to the matching ticket before the customer walks out. Orders speed up as the shift goes on, tips reward fast serves, and the last 30 seconds are a service rush.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network — the game is plain static files under `game/`. Mouse to click, keys 1–9 grab ingredients, Space chops, M mutes, Esc pauses. `main.ts` hands the game in: it copies `game/` and `screenshots/` to `/output` and writes `/output/dossier.json`.
